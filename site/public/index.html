Установка

Займёт минуту. Права администратора не нужны.

1

Скачайте установщик

Кнопка на этой странице берёт последнюю версию прямо из релизов на GitHub.

2

Запустите его

Лаунчер ставится только для вашего пользователя. WebView2 установщик добавит сам, если его нет.

3

Войдите и играйте

Через Microsoft или по нику. Игру и Java лаунчер скачает сам.

Синее окно «Windows защитила ваш компьютер»

Так Windows встречает программы без платной цифровой подписи. Нажмите «Подробнее», затем «Выполнить в любом случае». Код лаунчера открыт, установщик собирается на GitHub прямо из репозитория.
